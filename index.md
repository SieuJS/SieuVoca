# SieuVoca Documentation

This repository is the documentation source of truth for the SieuVoca IELTS study app and Chrome extension work.

## Start Here

- [IELTS Extension Documentation](./product/ielts-extension/index.md) - product scope, architecture, data model, extension behavior, website experience, risks, and backlog.

## Current Focus

The current product direction is an IELTSOnlineTests companion extension that helps learners save vocabulary, source context, notes, unsure markers, and practice-result data, then review that knowledge in the SieuVoca web app.

## Documentation Rule

Durable decisions should land in this repository first. Mintlify publishes approved docs from this repo, while Penpot, Linear, and pull requests link back to the canonical repo documents.
